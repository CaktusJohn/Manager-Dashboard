# Панель руководителя

Демоверсия для работы с данными заготовки, сварки и документации.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

После запуска откройте адрес, который покажет Streamlit (обычно `http://localhost:8501`).

При первом запуске выберите три исходных Excel-файла в боковом меню и нажмите «Импортировать данные». Данные сохраняются в `data/dashboard.db`; после этого исходные `.xlsx` можно удалить.

## Проверка данных и расчёты

Исходные записи в базе не изменяются автоматически. Перед показом и расчётом
для каждой записи создаётся временная оценка с двумя полями:

- `issues` — список найденных проблем;
- `is_valid` — `True`, если список проблем пуст, иначе `False`.

Для заготовки и документации обязательны идентификатор, дата, сотрудник,
план и факт; для сварки — идентификатор, дата, партия и потребность. Проверки отмечают пустые обязательные поля, повторяющийся `record_id`, план или потребность не больше нуля, отрицательный факт и факт более чем в два раза выше плана. Нулевой факт допустим.

План, факт и выполнение плана в KPI считаются только по корректным строкам.
Рядом выводится количество исключённых проблемных строк, поэтому итог не
выглядит достоверным без предупреждения.

Заготовка и сварка связаны по `batch_id`: баланс партии равен факту заготовки минус потребность сварки. Если факт заготовки отсутствует или хотя бы одна его строка некорректна, баланс этой партии не рассчитывается и помечается как «требует исправления». Документация от этих участков не зависит.

На панели директора выберите период и нажмите «Скачать отчёт CSV». Файл
открывается в Excel и содержит KPI, сводку по дням, сварку по партиям и список
проблемных исходных записей.
